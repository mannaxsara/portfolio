# Manna Sara Bilu — Personal Portfolio Website

Welcome to the repository for my personal website. This site serves as my digital portfolio — showcasing my projects, certifications, technical articles, and background at the intersection of data analysis, cyber-physical systems (IoT), and event technology infrastructure.

## ✨ Features

- **Responsive Retro Design**: Pixel-art and high-contrast theme built with custom Tailwind config.
- **Certifications Showcase**: Dynamic presentation of professional credentials (Google Data Analytics, Advanced Analytics, ACM-W, SAIL, IIITH).
- **Technical Articles**: Markdown-based articles on cloud-connected laboratories (RLabs) and time-series predictive forecasting models.
- **Interactive Dashboard**: Personal stat page featuring progress trackers, likes/dislikes logs, and interactive comment boards connected to Supabase.
- **Smooth Navigation**: Customized scrolling offsets and clean route transitions.

## 🛠 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript / JavaScript
- **Styling:** Tailwind CSS (v4)
- **Database:** Supabase
- **Content:** Markdown + Gray Matter
